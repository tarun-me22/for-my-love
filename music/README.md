## Optional: Add Synced Lyrics Files (`.lrc`)

You can also upload optional synced lyric files in this same `music/` folder, and the site will load and animate them automatically:

- `mrignaini.lrc`
- `maharani.lrc`

Example `.lrc` format:
```lrc
[00:24] First lyric line at 0:24
[00:29] Next lyric line at 0:29
[00:35] Another lyric line at 0:35
```

> **Note:** You can also paste or edit lyrics right inside the website using the **Edit Lyrics** button on the **Our Music** section, or inside `CONFIG.MUSIC.TRACKS` in `index.html`.
